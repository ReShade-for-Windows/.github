## Overview

ReShade is a generic post-processing tool for Windows games and video software. It provides a flexible environment for adjusting the final image with shaders and visual effects.

You can use ReShade with many different types of games, from older DirectX titles to modern DirectX 12 and Vulkan applications. The software supports Direct3D 9, Direct3D 10, Direct3D 11, Direct3D 12, OpenGL and Vulkan.

The main idea is simple: choose the application, configure the available effects and create a visual profile that matches your preferred style.
